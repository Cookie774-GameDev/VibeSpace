## Design

Keep the selected-STT adapter and existing Jarvis runtime as authorities. Propagate an optional confirmed `onTurnEnd` event through the selected-session ownership guard, then `voice:turn-end` through the Jarvis input adapter. Deliver finalized transcript first. Click-to-talk can submit its accumulated draft immediately on that event; hands-free modes retain their configured silence/commit behavior. An eager provider prediction is never authorization to execute a command.

No new provider charge, lower-quality model selection, speculative side effect, or fabricated acknowledgment is used to claim the latency target. Under 500 ms is a measured end-of-speech to first meaningful audible response target, not a promise of full tool completion or a timer-only unit test result.

User clarification: all three providers/models follow Settings. Panel-open warmup must use the selected speaking engine. The output router must not replace the selected engine with local Jarvis just because the panel is open; explicit per-turn selections remain authoritative for a streaming turn. The current turn-end optimization is specific to Flux's confirmed completion signal; ordinary segment finals from other STT engines retain their existing timing.

## Known scope gaps requiring explicit completion evidence

The archived plan calls for a Pipecat cascade, Cartesia, a speech-to-speech alternative, model-based intent classification, five personas, and speaker enrollment. The existing app has different provider/runtime contracts. Reuse is approved, but equivalence must be demonstrated; these features are not implemented merely by fixing turn detection. Cloud/provider availability, credentials, cross-platform wake-word checks, speaker enrollment, and under-500-ms performance remain unverified until independently completed.

Primary protocol reference: [Deepgram Flux state machine](https://developers.deepgram.com/docs/flux/state). `EndOfTurn` confirms a turn; `EagerEndOfTurn` may be followed by `TurnResumed`. This implementation uses confirmed completion only.
