## Target behavior

- Opening Jarvis voice follows **Main Agent chat: Resume or New**. Resume (the default) opens the last voice conversation for the chosen account, workspace, project, and provider. New creates a separate conversation folder. Closing and reopening voice does not cancel working native subagents or copy their full histories into the next chat.
- **Worker session: New or Resume** is an independent setting. New is the default. Resume reuses the last suitable provider-specific parent session, while every distinct user request still has a unique task ID. Codex and OpenCode handles remain separate.
- The selected Main Agent receives each transcript or mini-bar turn once, acknowledges promptly, and decides whether it can answer directly. Simple questions create zero workers. Work uses that provider's **native subagent** tools and reports actual provider, model, parent/child identity, progress, and terminal status. A saved Worker provider or one-request override must never silently change the saved Main provider.
- The existing Voice settings section controls Main/Worker provider, Main/Worker session mode, mini bar, selected STT/TTS/model, and optional provider/state accents plus intensity. Colors reflect real agent and work status; labels carry the same meaning without color. Startup red must correspond to a real error.
- “On my screen” captures one permitted screenshot. A failure still sends the text and tells the user briefly. Launch and worker failures return to the Main Agent as structured, truthful status. For a recoverable error, the Main Agent diagnoses and repairs it with its native tools, then retries within a bounded request; if it cannot fix the error, it reports the real limit briefly. No unproven launch or duplicate worker claim.
