Issue 08 / Boundaries

Issue 08 / Local by Design

Your keys stay yours.

Local-first is a boundary, not a mood. Chats, tasks, settings, schedules, and memory stay on the machine by default. Desktop API keys use the operating-system keychain. Telemetry is off by default. Cloud sync is optional.

  • 01Ollama can route supported local models offline and without a provider key.
  • 02Destructive actions and multi-terminal plans remain behind approval cards.
  • 03Declining an approval leaves the action unrun; malformed plans fail closed.
  • 04Optional cloud sync is a choice, not the default storage path.

Questions / Before install

The factual part.

Is Jarvis the product?

No. VibeSpace is the desktop AI workspace. Jarvis is the built-in assistant inside it.

Can VibeSpace work with local models?

Yes. Ollama support provides local, keyless routing for supported models. Model performance and hardware requirements depend on the selected model and computer.

What does “21+ providers” mean?

VibeSpace exposes a 21+ provider BYOK model hub. Live adapter availability can vary by release; the repository and current app are the source of truth.

Where are API keys stored?

Desktop provider keys use the operating-system keychain. This website never reads a real key; the vault shows a synthetic masked token only.

Do terminal plans run without approval?

Destructive Jarvis actions and multi-terminal orchestration are approval-gated. The terminal wall on this page is fictional and never executes a command.

Is cloud sync required?

No. VibeSpace is local-first, cloud sync is optional, and telemetry is off by default.

Which platforms are supported?

VibeSpace targets Windows, macOS, and Linux. Installer and signing status can vary by current release.

What works if WebGL is unavailable?

The complete written story, CSS/SVG fallback art, interactions, official links, FAQ, and directory remain. Three.js is an enhancement, not a content dependency.
